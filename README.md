# Chess Engine & AI

A custom chess engine and AI player built entirely in Python using PyCharm.

## Features
- Complete chess rules enforcement (moves, captures, checks)
- Visual board interface
- Integrated chess AI opponent

## How to Run
1. Make sure you have Python installed.
2. Install dependencies, Open your command prompt or terminal and run:
   ```bash
   pip install pygame-ce
   ```
3. Run the main file to start the game:
   ```bash
   python ChessMain.py
   ```
